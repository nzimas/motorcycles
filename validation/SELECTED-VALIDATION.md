Selected package validation executes the exact packaged MAIN rather than rebuilding the payload. `test_selected_configuration.py` verifies the baseline hashes, checksums/HMAC, protected sections, and every declared overwrite, rejecting undeclared baseline changes. `test_selected_boot.py` starts at the actual stock JSR at 0x40000530, follows the native/MACRO/TG chain, checks copies before erasure, TG reservation preservation, BSS initialization, register/stack replay, and the actual cache list initializer. `test_packaged_bootstrap.py` executes the package's protected decoder against its compressed MAIN.

The corrected native runtime occupies 0x46780000 onward within Model-TG's last reserved MiB, above MACRO's 0x46700000..0x4674f2f0. Earlier 0x43000000 placement overlapped the sample pool and is superseded; its reports are not evidence for readiness.

The emulator explicitly intercepts MOVEC ACR1 and records the intended value. It cannot prove cache semantics, SDRAM bus contention, peripheral boot, or an interrupt deadline. A masked instruction count is not a cycle bound: ColdFire instruction latency, cache misses and memory contention remain material. The earlier illustrative 28,880-instruction commit exceeds 0.153 ms audio headroom even at an unrealistically uniform one-cycle 135 MHz rate. Current sound staging and commit changes require fresh exact-candidate timing evidence; no prior timing figure authorizes deployment.
