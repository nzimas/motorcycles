Install

Patch your own firmware, in your browser

The patcher turns your own copy of the official Model:Cycles OS 1.13 into Motor:Cycles. It runs entirely on this page: nothing is uploaded and nothing is installed on your computer.

Drop the official OS 1.13 .syx here or click to choose the file Choose file…
Save Motor:Cycles .syx

Step by step

You need the official firmware file and Elektron Transfer. Back up your projects first.

  1. Download the official Model:Cycles OS 1.13 from elektron.se and unzip it.
  2. Drop its .syx file on the patcher above.
  3. Click Save Motor:Cycles .syx.
  4. Send the file to your Model:Cycles with Elektron Transfer, like an official update.

How it works

Only the official file

The patcher accepts nothing but the official OS 1.13 firmware. Any other file is refused.

Checked at every stage

It rebuilds the firmware exactly as the released build was made: the Modded-Cycles mods first, then Motor:Cycles. Each stage is checked against known checksums. The result is byte for byte the file tested on a real Model:Cycles, or nothing is produced.

No Elektron code here

The patch kit holds only the Motor:Cycles and Modded-Cycles changes. Your firmware file never leaves your computer.

Going back

To return to stock, install the official OS 1.13 with Transfer the same way.
